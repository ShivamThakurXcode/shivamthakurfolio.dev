ProDigiChat

A SaaS WhatsApp marketing and automation tool — broadcast campaigns, chatbot flows and a shared team inbox, built on the official WhatsApp Cloud API.

See the site live

// Category

SaaS Platform

// Stack

React · Node.js

// Timeline

2025

// Overview

A WhatsApp marketing tool that runs campaigns, automation and support from one number — broadcast to opted-in contacts, automate replies with visual chatbot flows, and answer everything from a shared team inbox on the official WhatsApp Cloud API.

// The problem

WhatsApp is where customers actually reply, but its raw API is unusable for a marketing team. They needed to send campaigns at scale, automate common questions and let a whole team answer from one number — without hitting rate limits or losing messages.

// What I built

A full-stack SaaS tool. A React dashboard drives campaigns, a drag-and-drop chatbot builder and a live inbox; a Node.js API talks to the WhatsApp Cloud API and takes inbound messages over webhooks. Broadcasts queue in Redis and go out through background workers that respect rate limits and retry failures, while WebSockets keep the shared inbox live for every agent.

React Node.js WhatsApp Cloud API Redis
FAQ

What is ProDigiChat?

ProDigiChat is a SaaS WhatsApp marketing and automation tool. Businesses use it to send broadcast campaigns, build automated chatbot flows, and handle incoming conversations from a shared team inbox — all on top of the official WhatsApp Cloud API.

How does ProDigiChat handle large broadcast campaigns?

Messages are pushed onto a Redis-backed job queue and sent by background workers that respect WhatsApp's rate limits. This keeps the dashboard responsive, retries failures, and lets a campaign to thousands of contacts run reliably without blocking the app.

What stack was used to build ProDigiChat?

A React dashboard, a Node.js API, Redis for queues and real-time state, WebSockets for the live team inbox, and the WhatsApp Cloud API for sending and receiving messages via webhooks.
