Backend Master: The Complete Backend Development Course

Learn backend development for free: Node.js, APIs, PostgreSQL, Redis, security, testing, scaling, Docker and system design in 36 hands-on chapters.

Backend Master is a free, 36-chapter course that takes you from how the internet works to designing and operating a production backend. It teaches Node.js, REST and GraphQL APIs, PostgreSQL, MongoDB and Redis, authentication and security, testing, caching, queues, scaling, Docker, CI/CD and system design through one running e-commerce project called ShopLine. Chapters 1 to 28 show real, executed code with the output we measured; later chapters are clearly labelled where examples were not run.

How to study this course

Read the chapters in order: each one builds on the ShopLine project from the one before, and the cross-links in the text point back to the chapter that introduced an idea. Run the code yourself, do the chapter quiz and the exercises, then move on. About 19 hours of reading in total. The lab files used in Chapters 13 to 29 are published in the resources folder, and Chapter 36 keeps the cheat sheets and the honest ledger of what was tested.

Backend Master: frequently asked questions

Is Backend Master really free?

Yes. All 36 chapters are free to read online with no sign-up or paywall. Each chapter includes the full text, the code, a 20-question quiz with an answer key, exercises, interview questions and project ideas.

What do I need to know before starting?

You should know basic JavaScript (variables, functions, async/await). Chapter 1 explains what a backend is, Chapter 4 covers the terminal and Git, and every later chapter introduces its own concepts from first principles, so no prior backend experience is needed.

Which technologies does the course use?

Node.js 22 with Express 5 and Fastify, PostgreSQL 17 as the main database, MongoDB, Redis, Docker, nginx and PgBouncer, plus libraries such as Zod, pino, BullMQ, argon2 and jose. The ShopLine e-commerce project evolves across all chapters.

Are the code examples tested?

Chapters 1 to 28 contain code that was actually run, with the real output shown, and each chapter says what was not run. Chapter 29 is partly tested (nginx and PgBouncer ran; replication did not). Chapters 30 to 36 were written without executing the examples and mark every new snippet as not run, so check them before using them in production.

In what order should I read the chapters?

In order. Part 1 covers networking, HTTP, Linux and Node.js internals; Part 2 builds APIs; Part 3 covers databases; Part 4 covers security, testing and reliability; Part 5 covers performance and scale; Part 6 covers deployment; Part 7 covers system design and a capstone project.
